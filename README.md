# MickeyWare-Releases-Dump
This is my public repository for all the versions of MickeyWare, a custom image of Ubuntu Linux.

# How to install
1. To get the ISO of a single version, go to the releases tab at the right and select the desired file. The file will get downloaded to your PC. 
2. Now, use a flashing tool (I recommend using balenaEtcher) to flash the ISO to your flash drive (preferrably USB3.0, should be at least 8GB or more!)
3. After the flashing is complete, plug the flash drive to the desired PC
